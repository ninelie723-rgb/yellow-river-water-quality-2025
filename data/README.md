# Data availability

Historical CSV and Excel files are excluded from this publication candidate while their provenance and redistribution terms are confirmed. No replacement or synthetic dataset is presented as the original data.

The archived project description attributes observations to the China National Environmental Monitoring Centre surface-water monitoring system. The exact download record, permission to redistribute, transformations and mapping between file versions remain unverified.

Obtain authorized inputs separately, check column names and encodings, and configure script paths before execution. Several inputs remain unresolved; see ../docs/REPRODUCIBILITY.md.
